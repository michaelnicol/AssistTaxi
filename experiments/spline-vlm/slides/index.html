From word2vec up to the model we actually train, SmolVLM2-2.2B. The sizes below are the ones in that checkpoint.

One list of numbers, then a photo, then a small edit.

A word is a list of numbers. A layer mixes those lists. The photo is turned into more lists of the same length and dropped into the sentence. LoRA is a small edit to four tables inside each language layer.

Words→ Photo cut into tiles→ 27 vision layers→ 81 lists per tile→ 24 language layers→ Next word→ LoRA, last

1. A token is one row of a table

Word2vec gave every word a list of numbers, and trained those lists so a word could predict its neighbors. This model still starts there. The lists live in one table, the embedding table. A token is one row. A token is a piece of text, often a word, sometimes a piece of a word.

The table has 49,280 rows, and each row is 2,048 numbers long.

A sentence is a sequence of those rows, in order. The sentence so far, including the words the model has already written, is the whole input to the next step. Nothing else about the words is kept.

2. One layer mixes the lists, then rewrites each one

The model does not jump from those lists to an answer. It repeats a layer. SmolVLM2’s language half has 24 of them. Each layer does two jobs, and then adds its result back onto the lists it was given, so a layer writes a change rather than a replacement.

Attention decides who matters

Each position makes three new lists from its 2,048 numbers, using three tables. Q is the question this position is asking. K is the label every position offers. V is the content that position will hand over if it is chosen. The match between one question and every label becomes a set of weights that add up to 1. Those weights mix the V lists. That mixture is what this position gathered from the rest of the sequence.

This happens 32 times in parallel. The 2,048 numbers are split into 32 heads of 64, because the checkpoint sets the head width at 64 and 2,048 ÷ 64 = 32. Each head can care about something different. A fourth table, O, stitches the 32 mixtures back into one list of 2,048. Q, K, V, and O are the four tables LoRA will touch. Each one is 2,048 by 2,048.

Order has to get in somewhere, because a bag of lists would not know which word came first. Before the comparison, Q and K are rotated by their position. The rotation is set so the sequence can run out to 8,192 positions.

The wide step rewrites one position at a time

Attention moved information between positions. The second half of the layer does not look at the neighbors. It rewrites each list on its own. Two tables expand 2,048 numbers to 8,192. Those two expansions are multiplied, and a third table brings the result back to 2,048. That result is added onto the list, the same way the attention change was.

One language layer: attention (Q, K, V, O, each 2,048 × 2,048), then the wide step (2,048 → 8,192 → 2,048). Twenty-four copies of that.

3. The last list picks the next token

After the 24th layer, the list at the end of the sequence is scored against every row of a second big table, the output table, also 49,280 by 2,048. Each score says how fitting that token is as the next piece of text. The highest score is written down, appended to the sequence, and the 24 layers run again. The model never writes the whole answer at once. It writes one token, then the next, until it stops.

Training is the same comparison used in reverse. We know which token should have won at each position of the lane text. Nudging the tables so that token’s score comes out on top is the whole of learning. The positions that belong to the question are left out of that score, so the model is trained on the lane lines and not on repeating the prompt.

4. The photo becomes more rows of the same table

The model only focuses a window 384 pixels wide. Each photo is 1276 by 717, so it is handed over as several looks. Twelve are close-ups. One is the whole photo, shrunk, so the pieces still have a map. That is 13, the usual setting.

More tiles keep the lane paint thick enough to see, and they cost more memory. These photos only land on eight counts. At 29 and 41, the card trains one photo at a time.

Each tile is a grid of patches

The eyes do not eat a tile as one blob. A tile is 384 pixels on the long side. A small convolution cuts it into patches of 14 by 14 pixels. 384 ÷ 14 lands on 27, so the tile becomes a 27 by 27 grid, 729 patches. Each patch is turned into a list of 1,152 numbers. A table of 729 position lists, one per grid cell, is added so the eyes know which patch was where.

Those 729 lists then go through their own stack of 27 layers. It is the same idea as the language layer: attention, then a wide step. The wide step here is simpler. It expands 1,152 numbers to 4,304 and brings them straight back. The language wide step was the gated one, 2,048 to 8,192 and back.

Packing makes them the same length as a word

729 lists of 1,152 is a lot to drop into the sentence. Neighboring patches are packed in 3 by 3 blocks. Nine lists of 1,152 become one list of 10,368, and 27 ÷ 3 = 9, so the grid goes from 27 by 27 to 9 by 9. That is 81 lists per tile. One linear table then maps each 10,368-list down to 2,048. That is the connector. After it, a tile is 81 rows of the same length as a word.

Usual setting, 13 tiles: 13 × 81 = 1,053 image rows, plus the words of the prompt, in one sequence.

The prompt is the sentence “Generate a list of splines for all road and taxi lines in this image.” The image rows replace the picture inside that sentence. From the first language layer on, a row that came from a patch and a row that came from a word are the same kind of object. The 24 language layers, and the next-token choice, do not have a separate path for the photo.

Each answer line the model writes is one lane, y_top y_bottom x1 x2 x3 x4, as fractions of the photo. Training scores only those answer tokens. The prompt tokens are marked so their scores do not move the tables.

5. LoRA edits four tables, and leaves the rest frozen

Full training, which is the default here, nudges every number in the eyes, the connector, and the 24 language layers. That is about 2.2 billion numbers. LoRA is the other switch. It freezes those tables and learns a correction that is added on when a table is used.

The correction is forced through 16 numbers. A table that is 2,048 by 2,048 holds about 4.2 million numbers. The two strips that stand in for a change are 2,048 by 16 and 16 by 2,048, which is 65,536 numbers. The strips are multiplied to act like a full-sized table, then doubled (the scale is 32 ÷ 16) and added onto the frozen result. During training, a random 5% of that correction is switched off, so the strips cannot memorize one photo.

The blue grid is one of those four tables, frozen. The yellow bar shrinks the list to 16 numbers, the green bar stretches it back, and the sum is added onto the original answer. The dot is only there to show that path.

Where the strips are pinned

There are 24 language layers and 4 tables in each, so 96 tables get a pair of strips. 96 × 65,536 is about 6.3 million numbers, a few in every thousand of the full model. The same kind of Q, K, V, and O tables exist in the 27 vision layers. Their names contain “vision,” and the training code skips any table whose name does. The eyes stay as pretrained. The connector stays as pretrained. Only the talking half learns the lane lines.

The path, once through

A token is a row of 2,048 numbers, taken from a table of 49,280 rows. Twenty-four layers mix those rows with attention and then rewrite each row in a wider table. The photo is cut into 384-pixel tiles, each tile into a 27 by 27 grid of patches, run through 27 smaller layers, packed 3 by 3, and mapped down to 2,048 so it can sit in the same sequence. The last row picks the next token, and the tokens we train are the lane lines. Full training nudges every table. LoRA freezes them and trains about 6.3 million numbers on Q, K, V, and O in the language layers only.
